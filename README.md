AvaliaEdu
Sistema web para gestão, correção e análise de avaliações educacionais, com foco em métricas como SAEB e SPAECE.

Funcionalidades:
Correção automática (OMR) de gabaritos via upload ou câmera

Gestão de alunos com desempenho e histórico

Dashboard de escolas com comparativos e evolução

Análise por habilidades (SAEB / SPAECE)

Gerenciamento de usuários (admin, diretor, professor)

Configurações completas do sistema

Visualizações com gráficos e indicadores

Objetivo
Facilitar a tomada de decisão educacional através de dados claros, organizados e acionáveis, melhorando o desempenho dos alunos e escolas.

Tecnologias utilizadas :
React + TypeScript

TailwindCSS

Recharts (gráficos)

Lucide Icons

Backend (API REST)

Como rodar o projeto
# instalar dependências
npm install

# rodar frontend
npm run dev
Backend
Certifique-se que a API está rodando em:

http://localhost:3000
Estrutura principal
StudentsPage → alunos e desempenho

SchoolsPage → visão por escola

ScanExamsPage → leitura de gabaritos

SkillsPage → habilidades SAEB/SPAECE

SettingsPage → configurações do sistema

UserManagementPage → controle de usuários
